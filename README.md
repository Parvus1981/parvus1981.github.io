# 🏠💰 Семейный бухгалтер

Семейное PWA-приложение для учёта бюджета: покупок, голосового ввода, распознавания чеков по фото, лимитов по категориям, накоплений-целей и AI-рекомендаций (Mistral), включая подбор выгодных покупок по акциям супермаркетов (Lidl, Hofer, Billa, Spar, Penny, Kaufland и свои).

Всё работает **без сервера**: данные хранятся только на вашем телефоне (localStorage), поэтому приложение бесплатно деплоится на GitHub Pages.

## ✨ Возможности

- 🎤 **Голосом**: «молоко 1.29, хлеб 2.40» → автоматом позиции, цены и категория
- 📷 **Фото чека**: распознавание текста (OCR, рус/нем/англ/укр) + умная чистка AI
- ⌨️ **Ручной ввод** текстом в свободной форме
- ✏️ **Черновик** перед сохранением — можно поправить название, количество, цену, категорию
- 🤖 **«Умная правка» (AI)** — исправляет ошибки распознавания и раскладывает по категориям
- 🏷️ **Категории**: еда, дети, отдых, коммуналка, транспорт, здоровье, одежда, дом/прочее
- 💰 **Лимиты бюджета** на месяц по каждой категории с цветовыми индикаторами
- 🎯 **Цели накопления** (отпуск, ремонт…) с прогресс-барами
- 📊 **Графики**: расходы по категориям, динамика за 6 месяцев
- 🤖 **AI-советник**: анализ трат и конкретные советы, где сэкономить
- 🏪 **Акции**: ссылки на страницы акций супермаркетов (список расширяется) + вставляете список акций → AI подбирает, что выгодно закупить именно вашей семье с учётом лимитов
- 🌐 **Оффлайн**: работает без интернета (Service Worker), устанавливается на главный экран
- 📦 Данные: экспорт/импорт JSON — удобно синхронизироваться между членами семьи

## 📲 Установка на телефон

1. Откройте адрес приложения в Chrome (Android) или Safari (iPhone).
2. Android: меню ⋮ → **Установить приложение**. iPhone: **Поделиться → На экран «Домой»**.
3. Иконка появится на главном экране — запускается как обычное приложение.

## 🚀 Деплой на GitHub Pages

1. Создайте в своём GitHub аккаунте **пустой публичный репозиторий**:
   - вариант «главная страница»: `parvus1981.github.io` → адрес приложения будет `https://parvus1981.github.io`
   - или любой другой, например `family-budget` → адрес `https://parvus1981.github.io/family-budget/`
2. Загрузите файлы репозитория (git push или через веб-интерфейс).
3. В репозитории: **Settings → Pages → Source: Deploy from a branch → main → /(root) → Save**.
4. Через 1–2 минуты приложение будет доступно по вашему адресу.

## 🤖 Подключить AI (бесплатно)

1. Зарегистрируйтесь на [console.mistral.ai](https://console.mistral.ai) и получите API-ключ (есть бесплатный тариф).
2. В приложении: вкладка **Ещё → AI-ключ (Mistral)** → вставьте ключ → Сохранить.
3. Появятся: «Умная правка» черновиков, разбор чеков AI, AI-советник и подбор акций.
   Без ключа приложение полностью работает: голос/OCR/ручной ввод понимаются встроенным парсером, графики и бюджет — локально.

> Ключ хранится **только в вашем браузере** и никуда не отправляется, кроме api.mistral.ai.

## 🗂 Структура

```
index.html            — интерфейс (единственная страница)
manifest.webmanifest  — PWA-манифест (установка на телефон)
sw.js                 — Service Worker (оффлайн)
css/styles.css        — оформление
js/storage.js         — хранение данных (localStorage), экспорт/импорт
js/parser.js          — категории + встроенный разбор текста (без интернета)
js/ai.js              — модуль Mistral AI (ключ в браузере)
js/app.js             — логика экранов, графики (Chart.js), OCR (Tesseract.js)
icons/                — иконки приложения
```

## 🔒 Приватность

- Никаких серверов и аккаунтов: бюджет живёт в браузере телефона.
- Делитесь данными экспорт-файлом с членами семьи.
- Очистить всё: **Ещё → Данные → Удалить всё** (двойное подтверждение).
