# 🏠💰 Семейный бухгалтер v2

Семейный PWABudget: голосовая корзина покупок с **мгновенным сравнением цен по акциям супермаркетов вашего города**, учёт расходов (голос/фото чека/рукой), лимиты по категориям, цели накоплений, AI-советник (Mistral). Главный сценарий v2: надиктовал корзину → «🔍 Где сегодня дешевле?» → таблица, в каком магазине (Lidl, Netto, REWE, Combi, Kaufland, PENNY…) какой товар сегодня по акции, расстояние и итог по каждой корзине.

Всё работает **без сервера**: данные только на вашем телефоне (localStorage), приложение живёт на GitHub Pages, а акции обновляет **GitHub Actions раз в день автоматически**.

## ✨ Что нового в v2

- 🛒 **Голосовая корзина**: «молоко, хлеб, 6 яиц, порошок» → список покупок → сравнение акций по каждому товару
- 🔍 **«Где сегодня дешевле?»**: для каждой позиции — лучшая акция в вашем городе (магазин, цена, скидка %, срок действия), итог по корзине в каждом магазине с учётом расстояния
- 🤖 **Автовобновление акций**: ежедневный workflow (`scripts/update-deals.mjs` → `data/deals.json`) собирает актуальные акции Marktguru по вашему индексу (~1300 предложений для 48431 Rheine)
- 🏪 **Магазины Райне**: K+K Klaas & Kock, Lidl, Netto, REWE, Combi, Kaufland, PENNY, Getränke Hoffmann, EDEKA, ALDI, dm, Rossmann — с настраиваемым расстоянием
- 🎙️ **Надёжный голос**: переписанный движок (Web Speech API с автоперезапуском), резерв — запись аудио → Voxtral (нужен бесплатный AI-ключ), распознавание на русском
- 💅 **Обновлённый дизайн**: градиентная шапка, тёмная тема, анимация микрофона, сетка акций

## 🚀 Ключевой сценарий

1. Вкладка **🛒 Купи** → жмите ⏺ и диктуйте: «молоко, хлеб, 6 яиц, порошок»
2. Корзина собрана → кнопка **«🔍 Где сегодня дешевле?»**
3. Смотрите: в Lidl молоко по акции 0,89 €, у вас 1 км; в Netto порошок −40 %…
4. Купили — жмите **«✔️ Куплено — внести в бюджет»**: цены из акций сразу попадут в учёт расходов

## 📱 Установка на телефон

1. Откройте [https://parvus1981.github.io](https://parvus1981.github.io) в Chrome (Android) или Safari (iPhone).
2. Android: меню ⋮ → **Установить приложение**. iPhone: **Поделиться → На экран «Домой»**.
3. Приложение работает офлайн (Service Worker), данные — только на устройстве.

## 🔁 Автообновление акций

- Файл списка магазинов: `config/terms.txt` (~130 немецких продуктовых терминов). Добавите слово — файл расширяется автоматически.
- Город/индекс: `config/settings.json` (`zip: "48431"`, Rheine).
- График: ежедневно (cron `30 5 * * *` UTC — обычно под утро, GitHub иногда запускает позже в течение дня), GitHub Actions коммитит `data/deals.json`; включить можно и вручную: **Actions → Обновление акций → Run workflow**.
- Приложение всегда тянет свежий `data/deals.json` (сеть прежде кэша), офлайн показывает последние сохранённые акции.

## 🔗 Ссылки на акции (v2.8)

- Какая-то сеть может дать свою прямую ссылку на акцию (например, Kaufland → filiale.kaufland.de) — тогда откроется она.
- Иначе открывается страница сети на Marktguru (`marktguru.de/r/<сеть>`) — там все актуальные акции и буклеты этой сети.
- Проверено: страницы всех сетей открываются (HTTP 200), ни одной «мёртвой» ссылки больше не будет.

## 🛍 K+K (Klaas & Kock)

В открытой базе Marktguru есть все местные сети **кроме K+K** (акции K+K не отдаются поиском API). Поэтому:
- для K+K в приложении есть **прямая ссылка на актуальные предложения** и
- обходной путь: скопируйте список акций с klaas-und-kock.de → вкладка **🏷️ Акции → AI-анализ** — ИИ подберёт выгоды под вашу корзину.

## 🤖 Подключить AI (бесплатно)

1. Зарегистрируйтесь на [console.mistral.ai](https://console.mistral.ai), получите API-ключ (есть бесплатный тариф).
2. **Ещё → AI-ключ (Mistral)** → вставьте → Сохранить.
3. Открываются: «Умная правка» черновиков, разбор чеков через AI, AI-советник, AI-анализ акций K+K и **резервное голосовое распознавание Voxtral** (если в браузере нет встроенного).

> Ключ хранится только в вашем браузере и отправляется только на api.mistral.ai.

## 🕸 Структура

```
index.html             — интерфейс (одна страница, 6 вкладок)
manifest.webmanifest   — PWA-манифест
sw.js                  — Service Worker (офлайн, свежие акции)
css/styles.css         — оформление (тёмная тема)
js/storage.js          — данные (localStorage), корзина, магазины
js/parser.js           — встроенный разбор текста «товар цена» (рус/нем)
js/deals.js            — матчинг корзины ↔ акции (русско-немецкий словарь)
js/voice.js            — голос: Web Speech API + Voxtral-резерв
js/ai.js               — модуль Mistral AI
js/app.js              — логика экранов, графики (Chart.js), OCR (Tesseract.js)
scripts/update-deals.mjs — сборщик акций Marktguru (запускает GitHub Actions)
config/settings.json   — индекс/город
config/terms.txt       — словарь продуктов для сбора акций
data/deals.json        — актуальные акции (коммитится Actions ежедневно)
.github/workflows/deals.yml — ежедневное обновление в 06:30 MEZ
```

## 🔐 Приватность

Никаких серверов: бюджет — в браузере телефона; ключ AI — тоже. Акции — публичный кэш Marktguru в вашем же репозитории.
